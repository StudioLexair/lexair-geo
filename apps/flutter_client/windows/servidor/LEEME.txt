VIGÍA (Lexair Geo) · Servidor integrado
=========================================

Este paquete es «todo en uno»: la aplicación incluye un servidor completo que
se levanta automáticamente al abrir VIGÍA. No necesita Internet ni configurar
nada para empezar a trabajar.

· Qué incluye
  servidor\pg\      Base de datos geográfica (PostgreSQL + PostGIS)
  servidor\node\    Motor del servicio de datos
  servidor\api\     Servicio de VIGÍA (esquema, importaciones, búsquedas)
  servidor\sql\     Catálogo del territorio (13 municipios, calles,
                    viviendas, puntos de interés y alias antiguos)

· Qué hace al arrancar
  1. Inicia la base de datos en el puerto 5433 (solo su máquina).
  2. Crea la base, sus migraciones y el catálogo del territorio.
  3. Solicita un usuario y una contraseña propios para crear la primera cuenta.
     Esta contraseña es temporal y deberá cambiarse al primer acceso.
  4. Inicia el servicio en http://127.0.0.1:3000 y conecta el cliente a él.

· Puertos
  Si el puerto está ocupado (por otra aplicación o por otra copia), el
  sistema elige automáticamente el siguiente libre (3001, 3002…) y le avisa
  en la pantalla de arranque. Para fijarlos usted mismo, cree el fichero
  %LOCALAPPDATA%\VIGIA\servidor-local.json con este contenido:
      { "puertoApi": 3000, "puertoBD": 5433 }

· Terminología editable
  Los nombres que ve en la interfaz (entidades, secciones, títulos) se
  personalizan con un fichero fácil de editar: terminologia.json en
  %PROGRAMDATA%\LexairGeo (o junto al ejecutable). Si no existe, se usan
  nombres neutrales. Ejemplo de contenido:
      {
        "sujetoSingular": "Profesor",
        "sujetoPlural": "Profesores",
        "paseSingular": "Permiso",
        "pasePlural": "Permisos",
        "kardexTitulo": "Profesores",
        "kardexTituloCorto": "PROFESORES",
        "importTitulo": "Importar profesores (Excel XML)",
        "unidadLabel": "Departamento"
  Cierre y abra VIGÍA para aplicar los cambios. Hay una plantilla de
  referencia en servidor\terminologia.ejemplo.json.

· Datos y registros
  Los datos se guardan en  %LOCALAPPDATA%\VIGIA\datos  (no se borran al
  desinstalar ni al actualizar) y los registros en %LOCALAPPDATA%\VIGIA\logs.

· Seguridad y red (pendiente)
  Esta compilación no está lista para producción ni para información real.
  PostgreSQL integrado utiliza autenticación trust para conexiones locales y
  la API no incorpora HTTPS por sí sola. La API puede escuchar en interfaces
  de red, incluso en una prueba local; el rol de servidor abre el firewall.
  Utilícela únicamente en un entorno de prueba aislado con datos ficticios.
  No la exponga a Internet ni a redes no confiables. La seguridad de red,
  las conexiones cifradas y los permisos deben completarse y probarse antes
  del despliegue. Las sesiones se invalidan al reiniciar la API integrada.

· Mapas
  Vea servidor\mapa\LEEME-MAPAS.txt para añadir la cartografía offline.

· Conexiones externas
  Administración → Conexiones de datos: configure la base de origen con el
  botón «Configurar» (servidor, puerto, servicio, usuario y contraseña) y
  pruebe la conexión antes de aplicar.
